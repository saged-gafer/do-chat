The Anatomy of a Ghost Message

We've eliminated the middleman. Here is exactly what happens when you hit send.

01

Direct Handshake

Devices establish a direct P2P connection via a zero-knowledge signaling server. Keys are exchanged locally.

02

Local Encryption

The payload is encrypted on-device using AES-256-GCM before it ever hits the network interface.

03

Direct Delivery

The encrypted packet travels directly to the recipient's IP address. No server stores the message in transit.

04

Secure Shredding

After 12 hours, local SQLite records are overwritten with random bytes and permanently deleted.
